\section{Introduction}
% An overview of the project objectives and scope.
The Aim of this project was to implement and evaluate various object detection algorithms on a custom dataset. The project was split up into the following sections:
\begin{itemize}
    \item Building a dataset:
          \begin{enumerate}
              \item Image collection,
              \item Image cleaning,
              \item Image annotation,
              \item Data analysis, and
              \item Data preprocessing.
          \end{enumerate}

    \item Object detection/ localization:
          \begin{enumerate}
              \item Implementation of two object detectors to detect sign type,
              \item Implementation of one object detector to detect a specific sign attribute, and
              \item Evaluation of the trained detectors, including metrics and visualizations.
              \item Analysis of input image, supporting the maintenance and monitoring of traffic signs. % whatever u say vro
          \end{enumerate}
\end{itemize}
The following steps were taken to ensure an equal and fair distribution of work among all group members:
\begin{itemize}
    \item For task 1, each group member contributed a similar number of annotated images to the dataset.
    \item For task 2, each team member was assigned one YOLO-based detector and one COCO-based detector to implement and evaluate.
\end{itemize}

\section{Data Preparation}
% Description of the dataset, annotation process, and data preprocessing steps.
To prepare the dataset for training, the following steps were taken:
\begin{enumerate}
    \item The images were collected manually from diverse locations on the island, and at different times of the day. The goal was to capture a solid variety of sing conditions, angles, and lighting scenarios.
    \item The collected images were then cleaned to remove any duplicates, after which, any recognizable faces or licence plates were obscured to ensure privacy. This was done both manually and using automated tools that can be found in the `Annotation Process' folder of the GitHub repository~\cite{github_repo} (all automated outputs were manually verified before moving onto the next step).
    \item The images were then annotated manually using LabelStudio as instructed. 
    \item {\color{red} todo: about merging datasets} %todo: this
    \item The combined dataset was then zipped and uploaded to the shared repository folder for easy access by all group members.
\end{enumerate}
